# Laulife — Tyrimo modulis (planavimo šaka)

Ši šaka (`claude/beautiful-bohr-k5mch0`) skirta būsimo Laulife tyrimo modulio planavimui ir prototipavimui — pagrindinis appsas čia neliečiamas.

Modulio tikslas: rinkti informaciją, ją atsirinkti, sisteminti ir daryti išvadas taikant mokslinį procesą (klausimas → hipotezė → įrodymai → vertinimas → išvada → peržiūra).

## Turinys

- `docs/PLANAS.md` — modulio planas: idėja, duomenų modelis, roadmap, sėkmės kriterijai, atviri klausimai.
- `docs/TYRIMAS.md` — atlikto researcho santrauka: esami įrankiai, moksliniai karkasai (GRADE, ACH, PRISMA, SIFT…), UX praktikos, duomenų modeliai, Laulife skirtukai.
- `prototype/tyrimo-modulis.html` — raw interaktyvus prototipas (vienas failas, atsidaro naršyklėje, duomenys saugomi localStorage). Jį tobuliname prieš keliant į appsą.

## Kaip pažiūrėti prototipą

Atsidaryk `prototype/tyrimo-modulis.html` naršyklėje — jokio serverio nereikia. Mygtukas „Atstatyti demo" grąžina pavyzdinius duomenis.
